# Topic 1: Project Setup

## What is it?
Setting up a React project using Vite or Create React App to start building web applications.

## Why Use React?

1. **Component-Based Architecture**
   - Build UI from small, reusable pieces
   - Each component manages its own logic and appearance
   - Easy to maintain and scale large applications

2. **Virtual DOM for Performance**
   - React updates only what changes, not the entire page
   - Faster rendering compared to traditional DOM manipulation
   - Better user experience with smooth updates

3. **Large Ecosystem & Community**
   - Thousands of libraries and tools available
   - Extensive documentation and tutorials
   - Active community for support and problem-solving

4. **Industry Standard**
   - Used by Facebook, Netflix, Airbnb, and many major companies
   - High demand for React developers in job market
   - Transferable skills to React Native for mobile apps

5. **Declarative Syntax**
   - Describe WHAT you want, React handles HOW
   - Easier to read and debug code
   - Less boilerplate compared to vanilla JavaScript

6. **One-Way Data Flow**
   - Data flows from parent to child components
   - Easier to track where data comes from
   - Predictable application behavior

## Key Concepts
- **JSX**: HTML-like syntax in JavaScript
- **Component**: A function that returns JSX
- **export default**: Makes component available to other files

## When to Use React
- Single Page Applications (SPAs)
- Interactive user interfaces
- Applications that need frequent UI updates
- Projects requiring reusable components
